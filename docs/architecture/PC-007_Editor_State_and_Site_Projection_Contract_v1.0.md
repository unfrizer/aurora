## Exact schema and Python models

The `state["editor"]` version-1 object has precisely the E-02 keys and
nested structure. Other top-level state entries are opaque and preserved.
Missing `editor` alone means uninitialized; present `null`, a malformed
object or an unsupported version is an error, never silently migrated or
overwritten. No defaults are inserted or inferred. The four public models
are frozen, slotted, keyword-only dataclasses with required fields:

| Model | Fields and types |
| --- | --- |
| EditorBrand | `name: str`; `tagline: str`; `primary_color: str`; `secondary_color: str`; `font_family: Literal["system", "serif", "monospace"]`; `logo_path: str \| None` |
| EditorSection | `id: str`; `heading: str`; `body: str`; `image_path: str \| None`; `image_alt: str` |
| EditorPage | `id: str`; `slug: str`; `title: str`; `meta_description: str`; `heading: str`; `sections: tuple[EditorSection, ...]` |
| EditorDocument | `schema_version: Literal[1]`; `language: Literal["ru", "en"]`; `brand: EditorBrand`; `pages: tuple[EditorPage, ...]` |

IDs must be canonical lowercase UUID strings, unique within the page
collection and across all sections, respectively. No UUID is generated by
P7. All required keys must be present, all other keys inside editor/brand/
page/section objects are rejected. Booleans are not accepted as version
integers. All text/path fields must have exact runtime `str` type, except
the explicitly nullable paths; lists become immutable tuples on load.
The snapshots are structural editor state, not P4-validated publishability.

## Codec and projection

The exact public call signatures are in ADR-013 E-03. `load_editor_state`
checks only the editor subtree of a runtime JSON object and returns detached
immutable models, or `None` only if the editor key is absent. It does not
validate unrelated top-level keys. `save_editor_state` validates the new
snapshot and any existing editor payload before replacement, deeply copies
all JSON-compatible outer state, preserves unrelated keys, and returns the
new object without modifying the input. Cycles, non-JSON values, non-finite
numbers and malformed keys cannot be copied into the result. Unsupported
existing editor versions are never clobbered. Model field errors, invalid
IDs, malformed JSON/state and unsupported versions raise a fixed sanitized
`EditorStateError(ValueError)`, never an input-bearing error.

`to_static_site_document` validates the structural editor snapshot and
requires an immutable tuple of `StaticSiteAsset` items. It constructs only
the exact P4 public model types; it drops editor-only IDs, preserves order,
maps matching presentation fields without modification, and passes the asset
tuple through without reading or validating asset bytes. P4's builder remains
the sole authority for slug/path/color/asset-signature/reference/homepage/
content-capacity validation and HTML compilation. P7 does not call P4's
builder/exporter implicitly, perform I/O, repair invalid drafts, or turn
opaque state into raw HTML.

Production imports: standard library; `JSONDict` from `src.core.types`;
and model types only from the public `src.site_export` gateway. No private
P4/P1/P6 files, provider/credentials, concrete Runtime or reverse import.
Tests may compose public P1/P4 APIs with temporary files.
